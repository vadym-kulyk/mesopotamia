# Сергій Жадан. «Месопотамія» — читання з завданнями

Навчальний сайт для 11 класу: усі дев'ять новел (Марат, Ромео, Іван, Маріо, Юра, Фома, Матвій, Боб, Лука), 50 частин, 500 запитань з автоперевіркою. За кожну новелу учень може набрати 100%. Є гра «Хто з якої історії?», 90 запитань для есе («Для допитливих») і жартівливі завдання для класу й онлайн-учнів («Разом»).

Результати учнів автоматично потрапляють у Google Таблицю вчителя.

## Налаштування таблиці (один раз, ~5 хв)

1. Відкрий таблицю **«Месопотамія — результати учнів»** на своєму Google Диску.
2. **Розширення → Apps Script**. Видали все в `Code.gs` і встав код із [`apps-script/Code.gs`](apps-script/Code.gs). Збережи (💾).
3. Угорі обери функцію `setup` і натисни **▶ Виконати**. Google попросить дозволи — підтверди (це твій власний скрипт). У таблиці з'являться аркуші «Результати» та «Есе».
4. **Розгорнути → Нове розгортання** → тип ⚙️ **Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі** (Anyone)
   
   Натисни **Розгорнути** і скопіюй адресу, що закінчується на `/exec`.
5. Встав цю адресу у файл [`config.js`](config.js) між лапками і збережи (на GitHub: олівець ✏️ → Commit changes).

## Що потрапляє в таблицю

- **Результати**: один рядок на учня — ім'я, відсоток за кожну з дев'яти новел (0–100%), гра (перша й найкраща спроба), кількість зарахованих есе. Рядок оновлюється, а не дублюється.
- **Есе**: кожна розгорнута відповідь із розділу «Для допитливих» — окремий рядок (учень, новела, запитання, відповідь, кількість знаків).

Сайт надсилає дані сам через 15 секунд після змін і коли учень закриває вкладку, а також за кнопкою «Надіслати в таблицю» на вкладці «Підсумок». Без імені нічого не надсилається.
